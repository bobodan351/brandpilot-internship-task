# Frontend Intern Task – Brand Onboarding Redesign

Welcome! This is a practical task for the Frontend Intern role.

## Goal

Your job is to **redesign and improve** the current onboarding experience.

Focus on:
- Better visual design and layout
- Improved spacing, typography, and hierarchy
- Excellent mobile responsiveness
- Smoother transitions and micro-interactions
- Overall polish and user experience

You do **not** need to connect to any real backend. The current flow already works with mock data.

## How to run the project

```bash
npm install
npm run dev
